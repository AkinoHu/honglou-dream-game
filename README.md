# 红楼·大观园梦 🏮

一款以《红楼梦》为题材的 **浏览器 3D 互动叙事游戏**。打开网页即玩，无需安装、无需账号、无需 API Key。

▶ **在线试玩：https://huminghua0901.github.io/honglou-dream-game/**

## 玩法
你扮演 **贾宝玉**，在 3D 低多边形风格的大观园里度过 **十五回** 光阴，每回分 **晨 / 午 / 暮** 三个时辰。

- **漫游大观园**：怡红院、潇湘馆、蘅芜苑、秋爽斋、栊翠庵、稻香村、沁芳亭、议事厅。
- **与人物交谈**：林黛玉、薛宝钗、史湘云、贾探春、王熙凤、妙玉、袭人、刘姥姥。每人有原著情节选项（送旧帕、共读西厢、看金锁、讨红梅、品体己茶……），影响好感与属性。
- **自由闲谈**：可输入任意文字和人物聊天。默认离线关键词台词；在"设置"中填入任意 OpenAI 兼容接口（OpenAI / DeepSeek / xAI 等）的地址、模型与 Key，人物即由大模型扮演（Key 仅存于本地浏览器）。
- **原著剧情事件**：元妃省亲 → 黛玉葬花 → 海棠诗社（诗词接句小游戏）→ 刘姥姥进大观园 → 湘云醉眠芍药 → 探春理家 → 抄检大观园 → 中秋联诗 → 锦衣军查抄。
- **簿册**：人物好感、金陵十二钗判词（好感≥50 解锁）、诗集收藏、回目记录与待发生事件提示。
- **六种结局**：木石前盟 / 金玉良缘 / 兰桂齐芳 / 因麒麟伏白首双星 / 悬崖撒手 / 白茫茫大地真干净。
- **存档**：每过一个时辰自动存档（localStorage），另有手动存读档。

### 操作
| 操作 | 键位 |
|---|---|
| 行走 | WASD / 方向键，或点击地面（手机点按） |
| 交谈 | 走近按 E，或点击人物 / 底部按钮 |
| 旋转视角 | 鼠标拖动，或 Q / R |
| 跳过时辰 | 右上"歇息" |

## 技术
纯静态网页：Three.js（已内置于 `vendor/`）+ 原生 ES Modules，无构建步骤。所有 3D 模型均为代码程序化生成。

本地运行：`python3 -m http.server` 后访问 `http://localhost:8000`。

参考 [@Saccc_c 的文章《手把手教你用 Opus 5.5 / Astra + Tripo 制作 3D 游戏》](https://x.com/Saccc_c/status/2110694725640474759)：用 AI 编程快速做出可玩的浏览器 3D 游戏。本作同样由 AI 全程编写；文中用 Tripo 生成 3D 模型，本作改为程序化低多边形建模，以保证零依赖、秒开。

## 目录
- `index.html` / `style.css` — 界面
- `js/main.js` — 3D 场景、操控、对话、事件、存档、结局
- `js/data.js` — 人物、地点、剧情、诗词、结局文本（可方便扩写）
