# 红楼·大观园梦 🏮

以《红楼梦》为题材的 **浏览器 3D 互动叙事游戏**。打开网页即玩：无需安装、无需账号、无需 API Key，电脑和手机都能玩。

▶ **在线试玩：https://akinohu.github.io/honglou-dream-game/**

## 故事
序章从石头记的开头讲起：女娲补天，剩下一块顽石，一僧一道将它化为通灵宝玉，接着入太虚幻境。之后你成为 **贾宝玉**，在大观园里度过 **十五回**，每回分 **晨、午、暮** 三个时辰。

## 玩法
- **漫游大观园**：怡红院、潇湘馆、蘅芜苑、秋爽斋、栊翠庵、稻香村、议事厅、沁芳亭。场景有曲面反宇飞檐、红柱、格扇窗、月洞门、长廊、太湖石、荷塘拱桥、竹林、红梅、垂柳。
- **九位人物**：黛玉、宝钗、湘云、探春、凤姐、妙玉、袭人、晴雯、刘姥姥。每人造型不同，有行走和待机动画，并按时辰在园中各处走动。
- **心事选项**：送旧帕、共读会真记、看金锁、扑蝶、芦雪广联句、送金麒麟、理家算账、讨红梅、品茶、撕扇、补裘……对话以原著文字为底本，每个选项耗一个时辰，影响好感，以及才情、家运、禅心三项属性。
- **自由闲谈**：可以随意打字。离线时使用意图识别对话引擎，按话题、好感层次回应，并避免重复。也可以在设置中接入任意 OpenAI 兼容的大模型（密钥只存在你的浏览器里）。
- **十一个回目过场**：元妃省亲、黛玉葬花、海棠诗社（诗词接句）、撕扇、刘姥姥进大观园、湘云醉眠、探春理家、宝玉挨打、抄检大观园、中秋联诗、锦衣军查抄。过场带宽银幕黑边、竖排回目标题卡和环绕镜头。
- **簿册**：人物好感、金陵判词（好感 50 解锁）、诗集收藏、回目记录、结局图鉴。
- **六种结局**：木石前盟 / 金玉良缘 / 兰桂齐芳 / 因麒麟伏白首双星 / 悬崖撒手 / 白茫茫大地真干净。
- **园图与小地图**：点击地名即可自动寻路前往，◆ 标出此刻可以触发的回目。
- **声音**：程序合成的古琴（五声音阶、吟猱滑音、混响），加上风声、鸟鸣、夜虫。三路音量可分别调节。
- **存档**：每过一个时辰自动存档，也可以手动存读，或导入导出存档文本。

### 操作
| 操作 | 电脑 | 手机 |
|---|---|---|
| 行走 | WASD / 方向键，或点击地面 | 左下摇杆，或点按地面 |
| 视角 | 拖动旋转、滚轮缩放、Q/R | 拖动旋转、双指缩放 |
| 交谈 | 走近按 E，或点击人物 | 点按人物或底部按钮 |
| 园图 / 簿册 | M / J | 底部按钮 |

## 技术
- 纯静态网页：Three.js r169（已内置于 `vendor/`）+ 原生 ES Modules，没有构建步骤。
- 渲染：ACES 色调映射、PCF 软阴影、Bloom 泛光、Sky 天空与 PMREM 环境反射、指数雾，晨、午、暮三种天色，夜晚有星月、灯笼点光与萤火。
- 所有模型、贴图（瓦、格扇、彩画、铺地、宣纸）和音乐都由代码生成，不加载任何外部美术或音频文件。人物立绘是把 3D 模型实时渲染成的半身像。
- 移动端会自动降低像素比、阴影分辨率和植被数量。

本地运行：`python3 -m http.server` 后访问 `http://localhost:8000`。

## 灵感
参考 [@Saccc_c《手把手教你用 Opus 5.5 / Astra + Tripo 制作 3D 游戏》](https://x.com/Saccc_c/status/2110694725640474759)（作品 *The Little Prince: Across the Stars*）。本作沿用它"AI 编写 + 多角度截图评审迭代"的流程；由于要做到零依赖、秒开，Tripo 生成模型的环节改为程序化建模。

## 目录
- `index.html` / `style.css`：界面（宣纸、印章、卷轴对话框、书法字体）
- `js/world.js`：3D 场景、建筑、植物、水面、天色、人物模型与动画、立绘
- `js/main.js`：游戏逻辑（操控、镜头、寻路、NPC 日程、对话、过场、诗社、结局、园图、教程、存档）
- `js/audio.js`：WebAudio 合成古琴与环境声
- `js/data.js`：人物、地点、剧情、诗词、结局文本（方便扩写）
